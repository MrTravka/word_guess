# Изменения

## 0.3.0 — 29.10.2026

- Добавлены серверные партии на 4/5/6 букв, шесть попыток, проверка существительных и повторных букв, нормализация Ё/Е, сдача и немедленная новая партия.
- Партии и строки сохраняются в SQLite. Одна активная игра на пользователя/длину; версии и ключи операций защищают от двойной отправки, конкуренции вкладок и потери ответа. Ошибка записи откатывает весь ход.
- Добавлены поле, экранная ЙЦУКЕН и физическая клавиатуры, раскрытие строк, обозначения помимо цвета, восстановление и итог с ответом. React Router и TanStack Query подключены с закреплёнными версиями.
- Подготовлены 10036 локальных толкований Викисловаря/Kaikki по CC BY-SA 4.0; 3652 из 3723 ответов имеют определение. Источник и лицензия показаны только после завершения партии.
- Сверены 6283 дополнительных слова только для ввода; всего 10006 допустимых вводов при неизменных 1119/1102/1502 ответах. Добавлены отчёты, воспроизводимые инструменты и лицензия.
- Проверены 70 pytest-тестов, TypeScript/Vite, браузерные сценарии production/Vite и Windows-подготовка. Docker остаётся непроверенным; экономика, кампания и PWA ещё впереди.

## 0.2.0 — 29.10.2026

- Добавлены регистрация без подтверждения, вход/выход и восстановление сессии; логины нормализуются, пароли хешируются Argon2id.
- Сессии хранятся в SQLite в виде хешей токенов, используются HttpOnly/SameSite cookie, срок действия и отзыв при выходе. Добавлены Secure для HTTPS, проверка Origin и ограничение перебора.
- Миграция `0002_accounts` атомарно добавляет аккаунты, сессии и отдельные настройки пользователей без изменения словаря.
- Добавлены формы аккаунта, главная после входа и настройки: системная, светлая и тёмная темы с сохранением на сервере и применением до React; синхронизация аккаунта между вкладками.
- Vite-прокси сохраняет Host для проверки Origin. Новая конфигурация сессий поддерживается в Windows и подготовленном Compose.
- Проверены 21 тест аккаунтов, 21 существующая проверка, TypeScript/Vite, Windows-подготовка и браузерные сценарии production/Vite на 360 px. Docker остаётся непроверенным; партии, экономика и PWA относятся к следующим этапам.

## 0.1.0 — 27.10.2026

- Добавлены основа React + TypeScript + Vite и FastAPI, стартовая страница с состоянием соединения и версией из API.
- Настроены SQLite с WAL, foreign_keys и busy_timeout, первая миграция Alembic и атомарный идемпотентный импорт подготовленного словаря.
- Добавлены `/api/health`, выдача собранного frontend с одного origin и ограничение доступа к исходникам и словарям.
- Добавлены `run.bat` и `run-dev.bat`: локальное окружение, зависимости по lock-файлам, сборка по изменениям, миграции/seed, остановка серверов.
- Подготовлены многоэтапный Dockerfile, Compose с постоянным SQLite volume и healthcheck. Полный запуск Docker не проверен: Docker в среде разработки отсутствует.
- Проверены чистая и повторная установка Windows в пути с пробелами, сохранность данных, API/SQLite и браузерная стартовая страница.
