# word_guess

Некоммерческая игра в русские слова по механике «5 букв»: веб-сервис с возможностью установки как приложение (PWA).

## Текущее состояние

Проект находится на этапе проектирования. Подготовлены [план реализации](plan.md), [правила работы](AGENTS.md) и референсы интерфейса. Код приложения, база слов, музыка и сценарии запуска еще не добавлены.

Выполненные этапы и критерии готовности отмечаются в [plan.md](plan.md). Этот README описывает фактическое состояние проекта и обновляется по мере разработки.

## Что запланировано

- Четыре режима: «4 буквы», «5 букв», «6 букв» и «Кампания».
- Шесть попыток на слово, русские существительные, экранная и физическая клавиатура.
- Регистрация по логину и паролю без подтверждения.
- Кампания с последовательной картой уровней и новым словом после поражения.
- Очки и монеты за победы; чем меньше попыток, тем выше награда.
- Рейтинг по режимам, магазин подсказок и коллекция косметических скинов.
- Сундуки каждые десять уровней с анимацией открытия.
- Светлая и темная темы, зеленый акцент, плавные анимации.
- Музыка из открытых источников, отдельные настройки музыки и звуков.
- Неограниченное число партий без энергии, рекламы и платежей.
- Не менее 1000 существительных каждой длины: 4, 5 и 6 букв. Объем и качество словаря еще предстоит проверить.

Правила, формулы наград, цены, вероятности и дополнительные идеи находятся в плане.

## Технические решения

Стек выбран для будущей реализации:

| Часть | Решение |
| --- | --- |
| Интерфейс | React, TypeScript, Vite |
| Сервер | Python, FastAPI |
| База данных | Только SQLite, и в Windows, и в Docker |
| Работа с БД | SQLAlchemy, миграции Alembic |
| Установка приложения | PWA |
| Проверки | pytest, Vitest, Playwright |

Версии зависимостей будут зафиксированы при создании приложения. Игровые ответы, очки, баланс, подсказки и призы рассчитывает сервер.

## Запуск

Приложение пока нельзя запустить: Dockerfile, compose.yaml и bat-файлы еще не созданы.

Планируются два способа:

| Окружение | Команда после реализации |
| --- | --- |
| Docker Compose | `docker compose up --build` |
| Windows без Docker | `.\run.bat` |
| Разработка в Windows | `.\run-dev.bat` |

После реализации здесь должны появиться проверенные требования к окружению, команды первого и повторного запуска, адрес сервиса и способы остановки.

## Данные и обслуживание

SQLite — единственная БД проекта. Будущие сценарии запуска должны сохранять аккаунты и прогресс между перезапусками; точный путь к файлу БД и Docker volume будет указан после реализации.

Переменные окружения, миграции, импорт слов, резервное копирование и восстановление пока не реализованы. Проверенные команды и расположение данных добавляются сюда вместе с соответствующей функциональностью.

PWA также еще не реализована. Инструкции установки и ограничения подключения будут добавлены после проверки на поддерживаемых устройствах.
